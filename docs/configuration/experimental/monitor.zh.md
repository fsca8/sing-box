!!! question "自 sing-box 1.8.0 起（monitor：仅本分支）"

### 结构

```json
{
  "max_size_mb": 100,
  "max_dns_rows": 200000,
  "max_conn_rows": 100000,
  "retention_days": 7
}
```

### 字段

所有字段均为可选：`0` 使用默认值，负数表示关闭该限制，正数表示覆盖默认值。

#### max_size_mb

监控数据库（`monitor.db`）的最大大小（MB）。

达到上限后优先删除最旧的记录：既由周期性维护执行，也由 SQLite 自身保证——即使写入突发，
数据库文件也不会超过该上限。

默认使用 `100`（100 MB），负数表示不限制。

#### max_dns_rows

监控数据库中保留的 DNS 记录条数上限。

优先删除最旧的记录。默认使用 `200000`，负数表示不限制。

#### max_conn_rows

监控数据库中保留的连接记录条数上限。

优先删除最旧的记录。默认使用 `100000`，负数表示不限制。

#### retention_days

服务启动时删除早于该天数的记录。

默认使用 `7`，负数表示关闭按时间的保留策略。
